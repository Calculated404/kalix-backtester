STRATEGY DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. DOUBLE RSI
   ───────────
   Source:      sentinel/indicators/double_rsi.py
   Entry:       Trend RSI > 60 (bullish) + Signal RSI cross above 40
   Exit:        Trend bias changes OR Signal RSI cross below 60
   Parameters:  trend_rsi_period=21, signal_rsi_period=7
   Risk Mgmt:   ATR-based stops (2x) and targets (3x)
   Best for:    Trending markets with shorter-TF mean reversion

2. TMV (Trend + Momentum + Volume)
   ────────────────────────────────
   Source:      sentinel/indicators/tmv.py
   Entry:       ALL three must align:
                • Smoothed Heikin Ashi bullish (green)
                • Range Filter buy signal
                • Volume > 30-period SMA
   Exit:        Trend bearish OR Range Filter sell
   Parameters:  ha_period=50, ha_smoothing=10, range_period=100
   Risk Mgmt:   ATR-based stops (2x) and targets (3x)
   Best for:    Strong trends with volume confirmation


HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Via Frontend:
  1. Start: python run_app.py
  2. Open: http://localhost:5003
  3. Check: "double_rsi" and/or "tmv" in Strategy selector
  4. Click: "Run backtest"

Via API:
  curl -X POST http://localhost:5003/api/run \
    -H "Content-Type: application/json" \
    -d '{"strategies": ["double_rsi", "tmv"], "period_years": 5}'

Via Python:

  Strategy = get_strategy_class('double_rsi')
  # Use with Backtest() class
